### 判定顺序（按顺序问，第一个答"是"的就是主轨，后面的不再问）

**问 1：主要产出是不是一个模型、预测或风险量化？**
判断依据：有训练集或拟合过程、有验证或外推、结果是对**未观测情形**的推断（未来病例数、风险地图、重症概率、结构构象、适应性突变）。
- 是 → `prediction`，**到此结束**，不再往下问
- 注意：出现 predict、model、forecast 这些词不算证据。只写"某指标是重症的预测因子"的描述性分析，不是问 1 成立
- **综述、系统评价、Meta 分析一律不成立问 1**，哪怕主题就是模型或算法。它们的主要产出是综合既有证据，按被综合的主题归轨：AI 辅助诊断的系统评价 → `virus-disease`；媒介能力研究的 Meta → `transmission`；沃尔巴克氏体效果的 Meta → `symbiont`
- **只把模型或算法当工具用**（用机器学习做物种鉴定、用软件做统计），但产出的是观测结果或新数据，也不成立问 1

**问 2：被操作或被测量的是菌、菌群或内共生菌吗？**
- 是 → `symbiont`

**问 3：被测量的是蚊虫的传递能力或决定它的媒介性状吗？**
指感染率、播散率、唾液腺感染率、外潜伏期、病毒载量、媒介能力；血餐偏好、寿命、适应性代价、行为、种群动态、种群遗传；杀虫剂抗性。
- 是 → `transmission`

**问 4：被研究的是病毒本身或病人吗？**
指病毒学与复制机制、致病与免疫、临床特征与分型、诊断方法、血清学调查、暴发调查、疾病负担。
- 是 → `virus-disease`

**问 5：被评估的是一项公共卫生措施吗？**
指疫苗与抗病毒药物、杀虫剂应用策略、蚊帐与个人防护、社区干预、指南与政策、卫生经济、监测体系与项目评估。
- 是 → `control-policy`

五问都不成立时 category 给 null，不猜。

### 三条易错边界

- **有菌 + 有传播测量**：只要对菌有操作或测量，主轨就是 `symbiont`，传播指标打标签。没有菌处理、只测蚊的传递能力，才是 `transmission`。
- **有实验 + 有模型**：看**主要贡献落在哪**。新数据 + 标准模型 → `transmission`；新方法 + 文献参数 → `prediction`。
- **clinical 关键词**："severity prediction"、"risk score"、"prognostic model" 且确有建模与验证 → `prediction`；仅报告重症的临床特征与危险因素 → `virus-disease`。

二、标签 tags：输出 1–6 个字符串。第一个必须从以下分类标签中选一个：{{categoryTags}}。其后可选 0–5 个适用标签，只能来自以下两个白名单：
- 主题：{{topicTags}}
- 实体：{{entityTags}}
没有适用的主题或实体时，只返回分类标签，不要凑标签。
首标签必须与内容的**形态**一致：有明确研究体系与结果的用"原始研究"；综述、Meta、观点、展望用"综述与观点"；新方法、检测手段、算法、数据集用"方法与工具"；现场或半野外干预与释放用"现场与中试"；监测、血清学、带毒率、暴发描述用"监测与流行病学"；临床特征与诊断用"临床与诊断"；疫苗与抗病毒药物用"疫苗与抗病毒"；指南、政策、共识用"指南与政策"；**构建、训练或验证了模型的用"预测与建模"**（模型类材料即使同时是原始研究，首标签也优先给"预测与建模"，因为这是它的主要贡献形态）。
主题标签按材料的实际内容选，最多 5 个：涉及哪种共生菌、哪种病原体、哪种传播效能指标、哪种预测方法、哪种干预手段、哪个蚊种、哪个研究阶段、哪个地域。**不要因为研究发生在实验室就省略蚊种，也不要因为标题没写就不打病原体标签——按正文实际内容打。**
**其他轨道的主题照打标签**：一篇归入 `symbiont` 的 Wolbachia 论文，若测了感染率与传播率，要打"媒介能力""感染率"；一篇归入 `prediction` 的登革预测论文，要打"登革""机器学习"。这些副标是跨轨关联的唯一依据，不能因为"不是主轨"就省略。

三、主体 subjects：资料实际讨论的机构或计划（不是顺带提及），用这些 id：{{entities}}。学术论文常常没有明确的机构主体（作者单位不算"主体"），这时给空数组，不要硬凑。

四、资料范围 scope：只根据这篇资料自身判断，不能从候选报道反推。
- single：一条材料只报道一项研究或一次发生。同一项研究的多个实验、多个时间点、多个剂量组、多个蚊种品系，都属于 single。
- composite：正文实质性报道多个可以各自成条的研究或事件。典型是：综述系统列举多项独立研究、大会摘要集、多地区暴发汇总、年度监测报告同时讲多个不相关事件。**注意：一篇综述若通篇在讲同一个主题的同一批证据，仍是 single；只有它逐项报道多个可以各自成条的研究时才判 composite。**
- unknown：材料不足以辨认范围。不要仅凭标题词、篇幅或是否能抽到 fact 判断。

五、事实 fact：抽取本条材料当前报道的那次发生，供同事实归组使用：title（≤30 字），subject（做出动作的主体），action（本次动作），object（动作的具体对象），occurredAt（原文明示的本次发生日期 YYYY-MM-DD，未知为 null）。composite 必须为 null；没有可确认发生的观点稿也可为 null。
- 学术材料的 subject 用**研究体系或研究对象**（例如"埃及伊蚊""沃尔巴克氏体 wMel 品系""云南边境伊蚊种群""某地登革监测数据"），不要用第一作者或期刊名。
- action 用研究动作：发现、报道、评估、构建、调查、比较、验证、释放、监测、预测。不要写成"发表"——发表是载体，不是这次发生。
- object 写这次动作的具体对象或核心结论的对象（例如"对登革病毒传播的阻断效力""某地伊蚊带毒率"）。
- occurredAt：学术材料以**原文标注的发表日期**为准（这是可信的、原文明示的日期）；只有"接受""在线""见刊"多个日期时，取与本条材料一致的那个。没有明示日期时给 null，不要用抓取时间补。
- 长期维护的数据库描述页、期刊栏目页、作者主页，若只是列出既有论文清单，不等于报道了新研究：scope 给 unknown、fact 给 null。

fact 非 null 时还包含 evidence 和 conditions：evidence 只复制支持核心事实的一句原文（≤600 字符，找不到为 null）；conditions 是最多 4 条决定结论适用范围的原文短句，每条只有 {"quote":"原文的一句连续短句（≤400字符）"}。本步骤不翻译、不概括条件，只摘录。
evidence 必须支持上面选定的当前动作。学术材料的 evidence 优先从摘要的结果句里摘，不要摘背景句或意义陈述句。
通读摘要全文后，条件优先级为：1. 研究体系与对照设置（体外/动物/半野外/现场、是否有阴性对照、样本量）；2. 适用边界（蚊种、菌株、病毒株、地区、时间窗、气候区间）；3. 明确写出的局限与外推限制。不要用"具有重要公共卫生意义"这类评价句占用条件名额。没有明确条件才给 []。
每个 quote 只承载一句原文；不同位置的条件分别成项，不能串成一个段落。例：原文有 "Experiments used a single colony." 和 "Field validation is pending."，应输出 [{"quote":"Experiments used a single colony."},{"quote":"Field validation is pending."}]，不能写成 "Experiments used a single colony... Field validation is pending."。保持原文语言和字符；超过长度就选较短的完整句子。不要翻译、改写、省略中间文字或自行加入 ... / …；拼接的引文会被丢弃。quote 必须是收到的原文正文/摘要里能连续查到的文字，不来自标题、来源标签或中文译文。

输出前核对一次主轨：先确认问 1 有没有被跳过。如果一条材料标题写"Wolbachia"，但摘要说的是"用 Wolbachia 阳性的蚊虫做样本、实际研究的是登革病毒在人群中的流行"，主轨应是 `virus-disease`；如果标题写"dengue outbreak"、实际做的是"比较带菌与不带菌蚊虫的传播率"，主轨应是 `symbiont`；如果标题写"dengue incidence"、实际做的是"训练模型预测下季度病例数"，主轨应是 `prediction`。以主要产出为准，不以标题关键词为准。

只输出一个 JSON 对象，字段：category, tags, subjects, scope, fact。
